# works_shafi

Personal website of Shafiul Islam: architecture, visualization and computational design.

**Live site:** https://shafiarch.github.io/works_shafi/

The front page is a bookshelf: each project is a book, and the open one shows its cover. Everything on the site is read from small JSON files, so projects and their contents can be added, removed or reordered without touching the code. Colors and type live in separate theme files that can be previewed before they go live.

See [GUIDE.md](GUIDE.md) for how to add a project, change a page, use a different theme, or put another website on the shelf.
